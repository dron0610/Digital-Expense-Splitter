# 💰 Digital Expense Splitter

## 📌 Project Overview

Digital Expense Splitter is a desktop-based application developed to simplify expense management among friends, family members, and groups.

The application helps users create groups, add members, record shared expenses, and calculate individual balances. It makes tracking shared expenses easier and reduces the confusion of manually calculating who owes whom.

## 🎯 Project Objectives

- Simplify the management of shared expenses.
- Allow users to create and manage different groups.
- Maintain records of group expenses.
- Calculate individual contributions and outstanding balances.
- Track who owes money and who needs to receive money.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Java | Core application development |
| Java Swing | Graphical User Interface (GUI) |
| JDBC | Database connectivity |
| MySQL | Database management |
| NetBeans IDE | Development environment |

## ✨ Key Features

- **User Authentication:** Login and signup functionality.
- **Group Management:** Create groups for friends, family, and trips.
- **Member Management:** Add members to existing groups.
- **Expense Management:** Record and manage shared expenses.
- **Balance Calculation:** Calculate individual shares and balances.
- **Owe Tracking:** Identify who owes money and who should receive money.
- **Database Integration:** Store user, group, member, and expense information in MySQL.

## ⚙️ How It Works

1. Users register or log in to the application.
2. Create a group based on the expense category, such as Friends, Family, or Trip.
3. Add members to the group.
4. Record expenses and their details.
5. The application calculates individual shares and balances.
6. Users can view who owes money and who needs to receive money.

## 🗄️ Database

**Database:** MySQL

The application uses JDBC to connect Java Swing with MySQL.

Main database entities include:
- Users
- Groups
- Members
- Expenses
